# CS-120-final
This project was built in my first year as a collaborative Python application that recommends recipes based on available ingredients.

One challenge I faced was organizing the program output. Initially, the program printed multiple ingredient matches for the same recipe, which made the results confusing. I revised the logic to count and display the exact number of matching ingredients per recipe, producing clearer and more meaningful output.

Another challenge was integrating the logic into a Tkinter interface. The program originally relied on terminal print statements, so I separated the core logic into functions and connected them to Tkinter buttons and labels. This allowed results to display dynamically in the GUI instead of the terminal.

I also improved how recipes were stored and displayed by restructuring the data so that each recipe clearly shows matching ingredients and a recipe link together. While working with dictionaries, I initially struggled with .items(), but clearer variable naming helped make the code easier to read and maintain.

Through this project, I strengthened my understanding of Python fundamentals, GUI development, and debugging through iteration.
